# Лабораторный практикум «Общеинженерная подготовка»

Методические указания к пяти лабораторным работам курса.

| Папка | Для кого | Что внутри |
| --- | --- | --- |
| `get-labs/` | студенты и преподаватели | методичка в формате Obsidian: теория, задания по ролям, стартовые наборы скриптов, примеры данных, карты понятий, навыков и инструментов |
| `Для преподавателей/` | только преподаватели | шпаргалки по работам, ответы на контрольные вопросы, эталонные скрипты. Это ссылка на отдельный закрытый репозиторий: без приглашения папка не открывается |

## Как открыть методичку

1. Установить [Obsidian](https://obsidian.md/).
2. Клонировать репозиторий.
3. В Obsidian открыть папку `get-labs` как хранилище и разрешить плагины, когда Obsidian спросит.
4. Начать с заметки **Лабораторный практикум**.

## Для преподавателей

Материалы преподавателя лежат в закрытом репозитории и подключены сюда в папку `Для преподавателей`. Чтобы получить к ним доступ:

1. Попросить владельца репозитория пригласить ваш аккаунт GitHub в закрытый репозиторий и принять приглашение.
2. Клонировать вместе с закрытой папкой:

``` bash
git clone --recurse-submodules <адрес этого репозитория>
```

Если репозиторий уже склонирован, подтянуть папку отдельно:

``` bash
git submodule update --init
```

После обновлений методички: `git pull` и `git submodule update`.
