# Лабораторный практикум «Общеинженерная подготовка»: комплект преподавателя

Методические указания к пяти лабораторным работам курса и материалы для тех, кто их ведёт.

| Папка | Для кого | Что внутри |
| --- | --- | --- |
| `get-labs/` | студенты и преподаватели | методичка в формате Obsidian: теория, задания по ролям, стартовые наборы скриптов, примеры данных, карты понятий, навыков и инструментов |
| `Для преподавателей/` | только преподаватели | шпаргалки по работам, эталонные скрипты измерений и обработки, разборы данных |

## Как открыть методичку

1. Установить [Obsidian](https://obsidian.md/).
2. Клонировать репозиторий.
3. В Obsidian открыть папку `get-labs` как хранилище и разрешить плагины, когда Obsidian спросит.
4. Начать с заметки **Лабораторный практикум**.

Шпаргалки в `Для преподавателей` — обычные Markdown-файлы, их можно читать прямо на GitHub.

## Что не выдавать студентам

Эталонные скрипты из `Для преподавателей` (`jetMeasure.py`, `jetProcessing.py`, `bloodProcessing.py` и другие) студентам не выдаются: скрипты сбора и обработки данных они пишут сами. В стартовых наборах методички лежат только скрипты для работы с приборами.
