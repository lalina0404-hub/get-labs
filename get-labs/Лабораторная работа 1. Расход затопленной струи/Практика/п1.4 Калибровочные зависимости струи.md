**Результат** — скрипт обработки `jetProcessing.py` переводит отсчёты АЦП в паскали, а шаги двигателя в метры. Обе калибровочные зависимости построены на графиках с формулами в легенде.

## Задание

### Что должно получиться

- [ ] Найдены коэффициенты прямой P = k·N + b для пересчёта отсчётов АЦП в давление — 1 балл
- [ ] Найдено перемещение трубки за один шаг двигателя — 1 балл
- [ ] График калибровки давления `pressure-calibration.png` — 1 балл
- [ ] График калибровки перемещения `distance-calibration.png` — 1 балл

### Как проверить

1. **Наклон правдоподобен.** Около 0,045 Па на отсчёт, то есть примерно 22 отсчёта на паскаль.
2. **Шаг правдоподобен.** Перемещение за шаг — сотые доли миллиметра, около 0,036 мм.

## Ход работы

Пока экспериментатор снимает свои данные, пишите скрипт на примере из стартового набора. В нём есть файлы калибровки давления `calibration/00 Pa.txt` и `calibration/45 Pa.txt`, а перемещение для примера такое: 500 шагов — 18 мм. Когда появятся свои файлы, замените пример на них.

### 1. Прочитать файлы

Скрипт экспериментатора из п1.1 сохраняет файл двумя столбцами: номер шага и средний отсчёт АЦП. Такие файлы читает одна функция NumPy:

``` python
import numpy as np

data = np.loadtxt(dataPath + "calibration/00 Pa.txt")
steps, adc = data[:, 0], data[:, 1]
```

Сразу отбросьте сбойные отсчёты АЦП: они на порядок больше остальных, см. [[т1.4 Экспериментальная установка струи#Датчик давления и АЦП|т1.4]]. Например, оставьте только точки, где отсчёт меньше 500 000: `adc = adc[adc < 500000]`. Эта строка понадобится и для всех файлов сечений.

### 2. Калибровка давления

По средним отсчётам двух файлов и давлениям, которые показал манометр, найдите прямую `np.polyfit(adc, pressure, 1)`. Как это делается и как оформить график — в [[о4 Калибровка и аппроксимация#^intro|о4]].

>[!success] Должно получиться так
>![[п1.4 Калибровка давления.png|450]]

Главное в калибровке 24-битного АЦП — **наклон**, паскали на отсчёт. Ноль давления плавает от записи к записи на сотни отсчётов, поэтому в п1.5 его будут брать для каждого профиля отдельно, а свободный член прямой не понадобится.

### 3. Калибровка перемещения

По числу шагов и перемещению, которые записал экспериментатор, найдите перемещение за шаг в метрах. Для двух точек (0 шагов — 0 мм и N шагов — L мм) это просто L / N, но оформите его так же, как калибровку давления: точки, прямая и формула в легенде.

### 4. Сохранить коэффициенты

Коэффициенты калибровок понадобятся во всех следующих заданиях. Оставьте их в переменных в начале скрипта и напечатайте в терминал:

>[!success] Должно получиться так
> ```
> k = 0.0452 Па/отсчёт
> 1 шаг = 3.6e-05 м
> ```
