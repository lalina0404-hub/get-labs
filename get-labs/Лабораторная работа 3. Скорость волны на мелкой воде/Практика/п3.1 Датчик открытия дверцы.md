**Результат** — геркон на кювете подключён к Raspberry Pi, и короткий скрипт однозначно сообщает о физическом открытии дверцы: ровно одно сообщение на одно открытие и ни одного, пока дверца закрыта.
^intro

## Задание

### Что должно получиться

- [ ] Схема датчика дверцы собрана на макетной плате и подключена к свободному GPIO
- [ ] Известно, какой уровень на входе соответствует закрытой и открытой дверце
- [ ] Скрипт ждёт открытия дверцы и печатает сообщение в момент открытия

### Как проверить

1. **Нет ложных срабатываний.** Пока дверца закрыта, скрипт ждёт сколько угодно долго. Касание проводов и стола его не запускает.
2. **Срабатывает каждый раз.** Пять открытий подряд — пять сообщений.

## Ход работы

### 1. Разобраться с герконом

Прочитайте [[т3.3 Датчик открытия дверцы#^intro|т3.3]]. Найдите геркон на кювете и магнит на дверце. Прозвоните геркон мультиметром: при закрытой дверце он должен быть замкнут, при открытой — разомкнут. Если наоборот, запишите это: уровни в скрипте будут обратными.

### 2. Выбрать вывод

Нужен свободный GPIO, не занятый АЦП и учебной платой. У большинства выводов Raspberry Pi после загрузки включена слабая встроенная подтяжка: у GPIO0–8 к питанию, у остальных к земле. Поэтому свободный вход читается постоянным значением, и это удобно для проверки: найдите вход, который без подключения стабильно читает одно и то же, а после сборки схемы меняет значение вместе с дверцей.

``` python
import RPi.GPIO as GPIO
GPIO.setmode(GPIO.BCM)
GPIO.setup(21, GPIO.IN)
for i in range(20):
    print(GPIO.input(21))
GPIO.cleanup()
```

В скриптах курса для дверцы использовался GPIO21.

### 3. Собрать схему

Соберите схему по рисунку из т3.3: один вывод геркона к 3,3 В, второй к GPIO, и от GPIO резистор 1 кОм на землю. Откройте и закройте дверцу, читая вход, и запишите, какой уровень что значит.

### 4. Написать ожидание

>[!success] Должно получиться так
> ```python
> import RPi.GPIO as GPIO
> import time
>
> doorPin = 21
> closedLevel = 1          # проверено на установке
>
> GPIO.setmode(GPIO.BCM)
> GPIO.setup(doorPin, GPIO.IN)
>
> try:
>     print("Ждём открытия дверцы...")
>     # ждать, пока вход равен closedLevel
>     # запомнить момент открытия и напечатать сообщение
> finally:
>     GPIO.cleanup()
> ```

Проверьте скрипт по пунктам «Как проверить». Этот кусок кода целиком войдёт в скрипт измерений из п3.2.
