**Результат** — проверено, что геркон на кювете правильно сообщает Raspberry Pi о положении дверцы, и написан короткий скрипт, который однозначно сообщает о её открытии: ровно одно сообщение на одно открытие и ни одного, пока дверца закрыта.
^intro

## Задание

### Что должно получиться

- [ ] Вход GPIO15 читается как 1 при закрытой дверце и 0 при открытой
- [ ] Скрипт ждёт открытия дверцы и печатает сообщение в момент открытия

### Как проверить

1. **Нет ложных срабатываний.** Пока дверца закрыта, скрипт ждёт сколько угодно долго. Касание проводов и стола его не запускает.
2. **Срабатывает каждый раз.** Пять открытий подряд — пять сообщений.

## Ход работы

### 1. Разобраться с герконом

Прочитайте [[т3.3 Датчик открытия дверцы#^intro|т3.3]]. Найдите геркон на кювете и магнит на дверце. Схема уже собрана: 3,3 В → геркон → GPIO15 (контакт 10), от GPIO15 резистор 1 кОм на землю. Прозвоните геркон мультиметром: при закрытой дверце он должен быть замкнут, при открытой — разомкнут.

### 2. Проверить вход

Читайте вход в цикле и открывайте и закрывайте дверцу:

``` python
import time
import RPi.GPIO as GPIO

GPIO.setmode(GPIO.BCM)
GPIO.setup(15, GPIO.IN, pull_up_down=GPIO.PUD_DOWN)
try:
    for i in range(50):
        print(GPIO.input(15))
        time.sleep(0.2)
finally:
    GPIO.cleanup()
```

При закрытой дверце должна читаться 1, при открытой — 0.

### 3. Написать ожидание

Скрипт собирается из трёх кусков. **Настройка входа** — как выше. **Ожидание**: цикл ничего не делает, пока вход равен уровню закрытой дверцы, и заканчивается, как только уровень сменился. Сразу после него запоминают время — от этого момента отсчитывается τ:

``` python
while GPIO.input(doorPin) == closedLevel:
    pass
start = time.time()
```

**Освобождение выводов** в блоке `finally`: он выполнится, даже если скрипт остановили `Ctrl+C`.

>[!success] Должно получиться так
> ```python
> import RPi.GPIO as GPIO
> import time
>
> doorPin = 15
> closedLevel = 1          # дверца закрыта — на входе 1
>
> GPIO.setmode(GPIO.BCM)
> GPIO.setup(doorPin, GPIO.IN, pull_up_down=GPIO.PUD_DOWN)
>
> try:
>     print("Ждём открытия дверцы...")
>     # ждать, пока вход равен closedLevel
>     # запомнить момент открытия и напечатать сообщение
> finally:
>     GPIO.cleanup()
> ```

Проверьте скрипт по пунктам «Как проверить». Этот кусок кода целиком войдёт в скрипт измерений из п3.2.
