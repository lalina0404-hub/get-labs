**Результат** — для каждого опыта построен график уровня воды от времени с отмеченным моментом прихода волны и скоростью. Все скорости нанесены на график теоретической зависимости c = √(gh), а проверка в логарифмических координатах показывает, подтверждается ли теория.
^intro

## Задание

### Что должно получиться

- [ ] Графики уровня воды от времени для каждого опыта с отмеченным моментом τ — 1 балл за три опыта и больше
- [ ] Скорость волны для каждого уровня, нанесённая на график опыта — 2 балла
- [ ] График теоретической зависимости c(h) с экспериментальными точками — 2 балла
- [ ] Наклон зависимости ln c от ln h с погрешностью, сравнение с ½ — 1 балл
- [ ] Необязательно: момент прихода волны находится скриптом автоматически — +1 балл

### Как проверить

1. **Скорости растут с глубиной.** Чем выше уровень, тем быстрее волна.
2. **Порядок величины.** При 100 мм скорость около 1 м/с, при 20 мм — около 0,44 м/с. При **L** = 1 м волна идёт до электродов от 1 до 2,3 с.
3. **Числа примера.** На примере данных:

| Глубина, мм | **τ**, с | **c**, м/с | √(gh), м/с | Расхождение |
| :---: | :---: | :---: | :---: | :---: |
| 20 | 2,15 | 0,47 | 0,44 | +5 % |
| 40 | 1,50 | 0,67 | 0,63 | +6 % |
| 60 | 1,06 | 0,94 | 0,77 | +23 % |
| 80 | 0,85 | 1,18 | 0,89 | +33 % |
| 100 | 1,16 | 0,86 | 0,99 | −13 % |

При 20 и 40 мм опыт совпадает с теорией в пределах нескольких процентов. При 60 и 80 мм волна быстрее теории на 20–30 %, а опыт при 100 мм ненадёжен: датчик у своего предела, и начало спада видно с опозданием, см. [[п3.3 Калибровка уровня воды#^intro|п3.3]]. Такие расхождения — повод для обсуждения в отчёте, а не ошибка скрипта.

## Ход работы

### 1. Уровень от времени

Для каждого опыта переведите отсчёты в уровень калибровкой из п3.5 и постройте время каждого отсчёта. Ноль времени — момент открытия дверцы: скрипт экспериментатора начинает запись именно тогда.

``` python
samples, duration, count = read(dataPath + "wave 60 mm.txt")
level = np.polyval(fit, np.clip(samples, minAdc, maxAdc))   # уровень, м
t = np.linspace(0, duration, count)                          # время, с
plt.plot(t, level * 1000)
```

Пять опытов обрабатываются одинаково, поэтому оформите это функцией, которая получает имя файла и возвращает `t` и `level`, и вызывайте её в цикле по списку уровней.

### 2. Момент прихода волны

>[!warning] Колебания после открытия дверцы — не волна
>Сразу после открытия уровень на записи качается с частотой около 4 Гц и размахом до 1,5 мм, особенно при 20 и 40 мм. Это от рывка дверцы дрожат кювета и провода электродов. Волна приходит позже — там, где уровень начинает падать и больше не возвращается. Не принимайте за приход волны первую впадину этих колебаний.

Колебания удобно убрать скользящим средним по 0,3 с — это длиннее их периода:

``` python
k = int(0.3 * count / duration)                  # отсчётов в 0,3 с
smooth = np.convolve(level, np.ones(k) / k, mode="same")
```

**Глазами и руками.** Постройте сглаженный уровень, увеличьте график вокруг излома и запишите τ для каждого опыта в список в скрипте.

**Скриптом (+1 балл).** Реализуйте метод двух прямых из [[т3.5 Момент прихода волны и проверка теории#Метод двух прямых|т3.5]] по сглаженному уровню:

1. средний уровень на участке, где волна заведомо не пришла, например от 0,2 до 0,5 с — первые доли секунды сглаживание искажает;
2. первая точка, где уровень опустился ниже среднего на несколько шумов, — грубая оценка начала спада;
3. прямая `np.polyfit` по начальной части спада, например по следующим 0,3 с;
4. τ — пересечение двух прямых.

### 3. Скорость на графике

Скорость c = L / τ. Отметьте τ на графике вертикальной линией, а L, τ и c подпишите в рамке на графике:

``` python
plt.axvline(tau, color="r", linestyle="--")
text = "L = %.2f [м]\nt = %.2f [с]\nV = %.2f [м/с]" % (L, tau, L / tau)
plt.text(x, y, text, bbox={"boxstyle": "round", "facecolor": "white", "alpha": 0.8})
```

>![[п3.6 Уровень воды после открытия дверцы.png|480]]
>
>Опыт при 40 мм из примера. Пунктир — уровень по датчику до прихода волны: 43,5 мм, на несколько миллиметров больше налитого, датчик чуть уплыл после калибровки. Красная линия — найденное τ = 1,50 с.

### 4. Сравнение с теорией

Постройте теоретическую кривую c = √(gh) для глубин от 0 до 120 мм и нанесите на неё экспериментальные точки. Глубина для каждого опыта — уровень, до которого налили воду по линейке: 20, 40, 60, 80, 100 мм.

>[!warning] Глубину не пересчитывайте через калибровку
>Уровень на записи до прихода волны, пересчитанный калибровкой, годится только для проверки датчика. Если датчик немного уплыл с момента калибровки, вместо 80 мм получится, например, 90 мм, и точка на графике съедет с теоретической кривой без всякой физической причины. Если уровень по датчику отличается от налитого больше чем на 5 мм, напишите об этом в отчёте: значит, калибровку надо повторить.

Затем постройте ln c от ln h, проведите прямую `np.polyfit(..., 1, cov=True)` и найдите наклон с погрешностью, как в [[о4 Калибровка и аппроксимация#Формулы метода наименьших квадратов|о4]]. Теория предсказывает наклон ½ и свободный член ½ ln g ≈ 1,14.

>[!success] Должно получиться так
>![[п3.6 Скорость от глубины.png|480]]
>
> ```
> Наклон: 0.50 ± 0.15 (теория 0.5)
> Свободный член: 1.23 ± 0.44 (теория 1.14)
> ```
> Пример данных: точки при 20 и 40 мм лежат на теоретической кривой, при 60 и 80 мм — выше, при 100 мм — ниже. Наклон всё равно совпадает с теорией в пределах погрешности, но погрешность большая — именно из-за разброса точек. Обсудите в отчёте, чем могут быть вызваны отклонения, см. [[т3.5 Момент прихода волны и проверка теории#Проверка теории|т3.5]].
