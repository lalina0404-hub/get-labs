## Задание

### Что должно получиться

- [ ] Найден многочлен, переводящий отсчёты АЦП в уровень воды — 3 балла
- [ ] График калибровки `height-calibration.png` с точками и кривой — 1 балл

### Как проверить

1. **Кривая проходит через точки.** Отклонение каждой точки калибровки от кривой — не больше пары миллиметров.
2. **Кривая не волнится.** Между точками калибровки кривая монотонна, без горбов и провалов.

## Ход работы

Начните на примере данных из стартового набора: скопируйте его в `wave/data` репозитория команды. Файлы уже разложены так же, как будут лежать свои: калибровка `20 mm.txt` … `100 mm.txt` — в папке `calibration`, опыты `wave 20 mm.txt` … `wave 100 mm.txt` — рядом.

### 1. Средние отсчёты

Прочитайте файлы калибровки функцией `read()` из [[о3 Raspberry Pi и АЦП#Формат файла с данными|о3]] и найдите средний отсчёт каждого. Файлы называются по уровню, поэтому их удобно читать в цикле:

``` python
dataPath = "wave/data/"
heights = [20, 40, 60, 80, 100]          # мм
adcMeans = []
for h in heights:
    samples, duration, count = read(dataPath + "calibration/%d mm.txt" % h)
    adcMeans.append(np.mean(samples))
```

### 2. Подобрать многочлен

Зависимость отсчёта от уровня нелинейная, см. [[т3.2 Датчик уровня воды#Вариант 1. Делитель напряжения|т3.2]], поэтому прямая не подойдёт. Начните со степени 2 и посмотрите, как кривая проходит через точки, потом попробуйте 3. Как выбирать степень и почему её нельзя завышать — в [[о4 Калибровка и аппроксимация#Аппроксимация|о4]].

``` python
levels = np.array(heights) / 1000        # м
fit = np.polyfit(adcMeans, levels, 3)
```

На примере данных многочлен третьей степени проходит через все пять точек с отклонением не больше 1,3 мм.

>[!warning] Точка, которая не ложится
>Если одна точка заметно выбивается из плавной зависимости остальных — например, при малой глубине смачивается только кончик электродов, — не включайте её в аппроксимацию и применяйте кривую только в диапазоне остальных точек. Напишите об этом в методике обработки.

### 3. Ограничить диапазон

Многочлен надёжен только между точками калибровки. Отсчёты за её пределами — например, когда почти вся вода вытекла — дадут бессмысленный уровень. Ограничьте их перед пересчётом:

``` python
data = np.clip(data, minAdc, maxAdc)
```
