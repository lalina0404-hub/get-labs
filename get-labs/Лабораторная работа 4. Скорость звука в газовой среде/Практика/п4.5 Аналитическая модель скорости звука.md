**Результат** — функция `speedOfSound()` в `soundFunctions.py` считает скорость звука во влажном воздухе с заданной долей CO₂. По ней построены зависимости скорости звука от доли CO₂ от 0 до 5 % для влажности аудитории и для 100 %, и найдены коэффициенты прямых, переводящих скорость звука в долю CO₂.

## Задание

### Что должно получиться

- [ ] Функция расчёта скорости звука при заданных температуре, влажности и доле CO₂ — 5 баллов
- [ ] Коэффициенты линейной зависимости доли CO₂ от скорости звука — 2 балла

### Как проверить

1. **Сухой воздух при 20 °C** без CO₂: около 343 м/с.
2. **Условия примера** — 22,6 °C, влажность 31,5 %, 0,04 % CO₂: около 345,4 м/с.
3. **Наклон.** Каждый процент CO₂ уменьшает скорость примерно на 0,8 м/с. Переход от влажности 31,5 % к 100 % ускоряет звук примерно на 1 м/с.

### 1. Сигнатура функции

В стартовом наборе заготовка:

``` python
def speedOfSound(temperature, h2oX, co2Max):
    co2X = []
    soundSpeed = []
    return co2X, soundSpeed
```

Функция получает температуру в °C, мольную долю паров воды и наибольшую долю CO₂ в процентах. Возвращает массив долей CO₂ от 0 до `co2Max` и массив скоростей звука для них. Сохраните эту сигнатуру: так функцию удобно вызывать дважды, для влажности аудитории и для 100 %.

>[!warning] Мольная доля, а не абсолютная влажность
>`h2oX` — мольная доля паров воды, безразмерное число около 0,01. Её считают по относительной влажности: `h2oX = rh * Pw0 / Pa`, см. [[т4.3 Состав воздуха, влажность и дыхание#Влажность|т4.3]]. Абсолютная влажность в кг/м³ — другая величина, подставлять её нельзя, хотя по порядку она похожа.

### 2. Шаги расчёта

>[!success] Должно получиться так
> ```python
> def speedOfSound(temperature, h2oX, co2Max):
>     # константы: R, молярные массы и степени свободы пяти газов
>     # T в кельвинах
>     # co2 — массив долей CO2 в сухом воздухе от 0 до co2Max / 100
>     # доли в сухом воздухе: N2, Ar постоянны, O2 = 0.2098 - co2
>     # доли во влажном: умножить сухие на (1 - h2oX), добавить h2oX
>     # M = сумма M_j * c_j, в кг/моль
>     # Cv = сумма (m_j / 2) * R * c_j, Cp = Cv + R
>     # c = sqrt(Cp / Cv * R * T / M)
>     return co2 * 100, soundSpeed
> ```

Считайте сразу массивами NumPy: если `co2` — массив, то и все доли, и M, и скорость получатся массивами без цикла.
