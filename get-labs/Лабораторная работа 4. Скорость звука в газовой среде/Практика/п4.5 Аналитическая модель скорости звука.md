## Ход работы

Формулы — в [[т4.2 Скорость звука в смеси газов#^intro|т4.2]] и [[т4.3 Состав воздуха, влажность и дыхание#^intro|т4.3]]. Положите `soundFunctions.py` и `soundProcessing.py` из стартового набора в `sound/scripts` репозитория команды и запускайте из корня репозитория: `python3 sound/scripts/soundProcessing.py`. В `soundFunctions.py` уже есть все числа из таблиц пособия: **R**, атмосферное давление `PA`, давление насыщенных паров `TEMPS`, `PW0`, молярные массы `M_…`, числа степеней свободы `I_…` и доли газов в сухом воздухе `X_…`. Ниже код разобран по кускам: часть строк дана целиком, часть нужно дописать по образцу. Вставляйте куски в заготовку по порядку.

### 1. Мольная доля паров воды

Термогигрометр показывает относительную влажность в процентах, а в формулы нужна мольная доля паров воды. Сначала находят давление насыщенных паров при температуре опыта — между точками таблицы значение берут по прямой, это делает `np.interp`. Затем — долю паров:

``` python
def h2oFraction(temperature, rh):
    pw0 = np.interp(temperature, TEMPS, PW0)   # давление насыщенных паров, Па
    h2oX = rh / 100 * pw0 / PA                 # мольная доля паров воды
    return h2oX
```

Проверка: `h2oFraction(21.9, 34)` ≈ 0,0088, `h2oFraction(21.9, 100)` ≈ 0,026.

>[!warning] Мольная доля, а не абсолютная влажность
>`h2oX` — безразмерное число около 0,01. Абсолютная влажность в кг/м³ — другая величина, подставлять её нельзя, хотя по порядку она похожа.

### 2. Скорость звука

Функция `speedOfSound(temperature, h2oX, co2Max)` получает температуру в °C, мольную долю паров воды и наибольшую долю CO₂ в процентах. Возвращает два массива: доли CO₂ от 0 до `co2Max` в процентах и скорости звука для них. Её пишут в пять шагов.

**а) Температура и доли CO₂.** Температуру переводят в кельвины. Доли CO₂ задают сразу массивом из 51 значения: тогда и все следующие величины получатся массивами, без цикла.

``` python
    T = temperature + 273.15
    co2 = np.linspace(0, co2Max / 100, 51)   # доля CO2 в сухом воздухе, от 0 до co2Max / 100
```

**б) Состав влажного воздуха.** CO₂ замещает кислород: их сумма в сухом воздухе постоянна, `X_O2` = 0,2098. Пары воды разбавляют все остальные газы в одинаковое число раз, `1 - h2oX`. Азот и кислород даны, аргон и CO₂ допишите по образцу:

``` python
    k = 1 - h2oX
    xN2 = X_N2 * k
    xO2 = (X_O2 - co2) * k
    xAr = ...
    xCO2 = ...
```

Проверка: при любой доле CO₂ сумма `xN2 + xO2 + xAr + xCO2 + h2oX` равна 1.

**в) Молярная масса смеси** — сумма молярных масс компонентов, умноженных на их доли. Допишите аргон, CO₂ и пары воды:

``` python
    M = M_N2 * xN2 + M_O2 * xO2 + ...
```

**г) Теплоёмкости смеси.** Молярная теплоёмкость компонента $C_v = \frac{m}{2} R$, у смеси — сумма по компонентам с их долями. Допишите остальные газы по образцу:

``` python
    Cv = (I_N2 * xN2 + I_O2 * xO2 + ...) / 2 * R
    Cp = Cv + R
```

**д) Скорость звука** по формуле $c = \sqrt{\gamma R T / M}$, где **γ** = Cp / Cv. Доли CO₂ возвращают в процентах:

``` python
    soundSpeed = np.sqrt(Cp / Cv * R * T / M)
    return co2 * 100, soundSpeed
```

Проверьте функцию до того, как идти дальше: при 20 °C без паров воды `speedOfSound(20, 0, 5)[1][0]` ≈ 343,4.

### 3. Две прямые

В `soundProcessing.py` впишите условия из `conditions.txt` (шаг 1) и вызовите функцию дважды: для влажности аудитории и для 100 % (шаг 2). Каждую зависимость аппроксимируйте прямой, где **x — скорость звука, y — доля CO₂**: тогда прямая сразу переводит измеренную скорость в долю.

``` python
t, rh = 21.9, 34      # из conditions.txt

co2, speedRoom = s.speedOfSound(t, s.h2oFraction(t, rh), 5)
co2, speedWet = s.speedOfSound(t, s.h2oFraction(t, 100), 5)

fitRoom = np.polyfit(speedRoom, co2, 1)
fitWet = np.polyfit(speedWet, co2, 1)
print("Прямая, влажность аудитории:", fitRoom)
print("Прямая, влажность 100 %:", fitWet)
```

>[!success] Должно получиться так
> ```
> Прямая, влажность аудитории: [ -1.255  432.97]
> Прямая, влажность 100 %: [ -1.267  438.29]
> ```
> Первое число — наклон: −1,25 % CO₂ на 1 м/с, то есть 1 % CO₂ — это 0,8 м/с. Второе — свободный член.
