**Результат** — функция `speedOfSound()` в `soundFunctions.py` считает скорость звука во влажном воздухе с заданной долей CO₂. По ней построены зависимости скорости звука от доли CO₂ от 0 до 5 % для влажности аудитории и для 100 %, и найдены коэффициенты прямых, переводящих скорость звука в долю CO₂.

### Что должно получиться

- [ ] Функция расчёта скорости звука при заданных температуре, влажности и доле CO₂ — 5 баллов

### Как проверить

1. **Сухой воздух при 20 °C** без CO₂: около 343 м/с.
2. **Условия примера** — 21,9 °C, влажность 34 %, 0,04 % CO₂: около 345,0 м/с.
3. **Наклон.** Каждый процент CO₂ уменьшает скорость примерно на 0,8 м/с. Переход от влажности 34 % к 100 % ускоряет звук примерно на 1 м/с.

## Ход работы

Все формулы — в [[т4.2 Скорость звука в смеси газов#^intro|т4.2]] и [[т4.3 Состав воздуха, влажность и дыхание#^intro|т4.3]].

### 1. Заготовка

В стартовом наборе `soundFunctions.py`. В нём уже есть все константы из таблиц т4.2 и т4.3: R, атмосферное давление, давление насыщенных паров, молярные массы, степени свободы и доли газов в сухом воздухе. Есть две функции, в которых шаги расписаны комментариями, — вам нужно записать формулы.

| Функция | Получает | Возвращает |
| --- | --- | --- |
| `h2oFraction(temperature, rh)` | температуру, °C, и относительную влажность, % | мольную долю паров воды |
| `speedOfSound(temperature, h2oX, co2Max)` | температуру, °C, мольную долю паров воды, наибольшую долю CO₂, % | массив долей CO₂ от 0 до `co2Max`, %, и массив скоростей звука для них |

Не меняйте имена и аргументы функций: `speedOfSound()` удобно вызывать дважды — для влажности аудитории и для 100 %.

>[!warning] Мольная доля, а не абсолютная влажность
>`h2oX` — мольная доля паров воды, безразмерное число около 0,01. Её считают по относительной влажности, см. [[т4.3 Состав воздуха, влажность и дыхание#Влажность|т4.3]]. Абсолютная влажность в кг/м³ — другая величина, подставлять её нельзя, хотя по порядку она похожа.

### 2. Шаги расчёта

Шаги — в комментариях заготовки. Считайте сразу массивами NumPy: если `co2` — массив из `np.linspace(0, co2Max / 100, 51)`, то и все доли, и M, и скорость получатся массивами без цикла. Например, молярная масса смеси:

``` python
M = M_N2 * xN2 + M_O2 * xO2 + M_AR * xAr + M_CO2 * xCO2 + M_H2O * h2oX
```

В конце верните доли CO₂ в процентах: `return co2 * 100, soundSpeed`.

Проверьте функцию по пунктам «Как проверить» до того, как идти дальше.

### 3. Две прямые

Вызовите функцию для влажности аудитории из `conditions.txt` и для 100 %. Каждую зависимость аппроксимируйте прямой, где **x — скорость звука, y — доля CO₂**: тогда прямая сразу переводит измеренную скорость в долю.

``` python
import numpy as np
import soundFunctions as s

t, rh = 21.9, 34      # из conditions.txt

co2, speedRoom = s.speedOfSound(t, s.h2oFraction(t, rh), 5)
co2, speedWet = s.speedOfSound(t, s.h2oFraction(t, 100), 5)
fitRoom = np.polyfit(speedRoom, co2, 1)
fitWet = np.polyfit(speedWet, co2, 1)
```

Напечатайте коэффициенты обеих прямых: они войдут в отчёт.
