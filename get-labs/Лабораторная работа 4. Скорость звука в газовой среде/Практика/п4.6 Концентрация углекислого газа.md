### Как проверить

1. **Воздух.** Доля CO₂ в атмосферном воздухе — около 0,04 %. Из-за погрешности измерения задержки у вас может получиться от −5 до 3 %: это нормально, и это надо обсудить.
2. **Выдох.** В выдохе после задержки дыхания доля CO₂ — несколько процентов, обычно 2–7 %.

## Ход работы

### 1. Задержка

Задержку измеряют по графику, как курсорами: строят оба сигнала с осью времени в миллисекундах, увеличивают начало импульса и наводят мышь на одинаковые точки двух сигналов. Внизу окна Matplotlib показывает координаты точки под курсором.

1. Постройте запись. Время отсчётов: шаг 4 мкс, а микрофон 1 измеряется на 2 мкс позже микрофона 0, см. [[т4.5 Экспериментальная установка трубы#Время в записи|т4.5]], — эта поправка уже в оси `time1`. Фон вычитаем, чтобы оба сигнала начинались с нуля и их форму было легко сравнить:

``` python
import numpy as np
import matplotlib.pyplot as plt

name = "air1"
mic0 = np.loadtxt(name + "_0.txt")
mic1 = np.loadtxt(name + "_1.txt")

mic0 = mic0 - np.mean(mic0[:200])   # фон — первые 200 отсчётов, до импульса
mic1 = mic1 - np.mean(mic1[:200])

time0 = np.arange(len(mic0)) * 0.004   # мс
time1 = time0 + 0.002                  # микрофон 1 на 2 мкс позже

plt.plot(time0, mic0, label="микрофон 0")
plt.plot(time1, mic1, label="микрофон 1")
plt.xlabel("Время, мс")
plt.legend()
plt.grid()
plt.show()
```

2. Включите лупу на панели окна и выделите начало импульса микрофона 0 — место, где сигнал отходит от нуля. Найдите на нём заметную точку: первый горб или провал. Наведите на неё мышь и запишите время $t_0$.
3. Кнопкой «домой» верните весь график, увеличьте начало импульса микрофона 1, примерно на 3,3 мс правее. Найдите **ту же** точку — форма начала импульса у микрофонов почти одинаковая — и запишите $t_1$.
4. Задержка $\tau = t_1 - t_0$. Отметьте той же точкой все записи воздуха и выдоха и сведите результаты в таблицу.

>

> Воздух: τ = 3.32–3.35 мс, c = 345–349 м/с

>[!warning] Не берите самый высокий пик
>Сравнивайте самое начало воздушного импульса. Поздние пики выше, но они могут быть отражениями от концов трубы. Если задержка вышла в доли миллисекунды, вы поймали волну по металлу трубы, а не по воздуху. Подробнее — в [[т4.4 Время пролёта звука между микрофонами#Что ещё есть на записи|т4.4]].

Задержка $\tau = N \cdot 4$ мкс $+ 2$ мкс.

### 2. Скорость и доля CO₂

Скорость звука c = L / τ, L = 1,158 м. Долю CO₂ найдите прямыми из п4.5: для атмосферного воздуха — прямой для влажности аудитории, для выдоха — для 100 %.

``` python
co2Air = np.polyval(fitRoom, cAir)
co2Breath = np.polyval(fitWet, cBreath)
```

Если опытов было несколько, найдите среднюю скорость и её разброс, и по разбросу — погрешность доли CO₂.

>[!success] Должно получиться так
>При 21,9 °C и 34 % из примера `conditions.txt` скорость в воздухе по модели — 345,0 м/с, τ = 3,356 мс. Пример данных даёт CO₂ от −4,5 до −0,3 % в воздухе и 2–3 % в выдохе, смотря какую точку отметить. Отрицательная доля в воздухе — не ошибка расчёта: измеренная задержка короче теоретической всего на несколько отсчётов, а это и есть точность ручной отметки. Поиск сдвига программой даёт −1,8 % и 3,0 %.

### 3. Итоговый график

Нанесите обе точки на график из п4.5, а скорость и долю подпишите в легенде:

``` python
plt.plot(co2Air, cAir, "*", label="Воздух: %.1f [м/с], %.1f [%%]" % (cAir, co2Air))
```

>[!info] Оценка точности
>При τ ≈ 3,4 мс ошибка τ в один отсчёт, 4 мкс, даёт ошибку скорости около 0,4 м/с, а это примерно 0,5 % CO₂. Ручная отметка ошибается на несколько отсчётов, то есть на 2–4 % CO₂; поиск сдвига программой точнее. Поэтому доля CO₂ в атмосферном воздухе, 0,04 %, этим методом не различима, зато несколько процентов в выдохе — различимы. Это ответ на первый контрольный вопрос, и его стоит дать в отчёте числами.
