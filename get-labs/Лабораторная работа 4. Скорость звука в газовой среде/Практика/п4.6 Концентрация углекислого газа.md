## Ход работы

Пока экспериментаторы снимают свои записи, работайте с записями `air1` и `breath1` из примера данных: скопируйте файлы из `Стартовый набор/Пример данных` в `sound/data`. Потом замените их своими.

### 1. Задержка

Задержку измеряют по графику, как курсорами на осциллографе: строят оба сигнала с осью времени в миллисекундах, увеличивают начало импульса и наводят мышь на одинаковые точки двух сигналов. Внизу окна Matplotlib показывает координаты точки под курсором.

Для просмотра записей сделайте отдельный скрипт `soundView.py`. Он короткий, его можно взять целиком:

``` python
import numpy as np
import matplotlib.pyplot as plt

dataPath = "sound/data/"
name = "air1"   # какую запись смотрим: air1, air2, breath1, ...

mic0 = np.loadtxt(dataPath + name + "_0.txt")
mic1 = np.loadtxt(dataPath + name + "_1.txt")

mic0 = mic0 - np.mean(mic0[:200])   # вычитаем фон, первые 200 отсчётов до импульса
mic1 = mic1 - np.mean(mic1[:200])

time0 = np.arange(len(mic0)) * 0.004   # время отсчётов, мс: шаг 4 мкс
time1 = time0 + 0.002                  # микрофон 1 измеряется на 2 мкс позже

plt.plot(time0, mic0, label="микрофон 0")
plt.plot(time1, mic1, label="микрофон 1")
plt.xlabel("Время, мс")
plt.legend()
plt.grid()
plt.show()
```

Что в нём происходит:

- **Фон.** Постоянные уровни микрофонов разные, около 870 и 960. Если вычесть из каждого сигнала его среднее до импульса, оба начнутся с нуля и их форму легко сравнить. Фон берут по первым 200 отсчётам, а не по всем 512 до срабатывания: импульс начинается раньше, чем срабатывает запись, см. [[т4.5 Экспериментальная установка трубы#Как проходит запись|т4.5]].
- **Время.** Отсчёт номер i сделан в момент i · 4 мкс. Микрофон 1 Pico измеряет на 2 мкс позже микрофона 0, поэтому к его времени прибавляют 0,002 мс. После этого задержку можно читать прямо по оси времени.

Запустите из корня репозитория команды: `python3 sound/scripts/soundView.py`. Затем:

1. Включите лупу на панели окна и выделите начало импульса микрофона 0 — место, где сигнал отходит от нуля. Найдите там заметную точку: первый провал или горб. Наведите на неё мышь и запишите время $t_0$.
2. Кнопкой «домой» верните весь график и увеличьте начало импульса микрофона 1, примерно на 3,4 мс правее. Найдите **ту же** точку — начало импульса у микрофонов почти одинаковое по форме — и запишите $t_1$.
3. Задержка $\tau = t_1 - t_0$.
4. Поменяйте `name` и повторите для всех записей воздуха и выдоха. Выбирайте одну и ту же точку во всех записях.

>[!success] Должно получиться так
>![[п4.6 Задержка по графику.png]]
>
>Запись `air1`: отмечен первый провал, $t_0$ = 1,296 мс, $t_1$ = 4,662 мс, **τ** = 3,366 мс. В записи `breath1` удобнее взять первый горб: 2,452 и 5,826 мс, **τ** = 3,374 мс.

>[!warning] Не берите самый высокий пик
>Сравнивайте самое начало импульса. Поздние пики выше, но это могут быть отражения от концов трубы. Если задержка вышла в доли миллисекунды, вы поймали волну по металлу трубы, а не по воздуху, см. [[т4.4 Время пролёта звука между микрофонами#Что ещё есть на записи|т4.4]].

Ручная отметка ошибается на несколько отсчётов: соседние точки одной записи дают задержки, отличающиеся на 0,01–0,02 мс. Поэтому выбирают одну и ту же точку во всех записях и усредняют несколько опытов.

### 2. Скорость и доля CO₂

Впишите задержки в `soundProcessing.py` (шаг 3) списком, по одной на запись. Скорость звука **c** = **L** / **τ**, задержку переводят из миллисекунд в секунды. Долю CO₂ находят прямыми из п4.5: для атмосферного воздуха — прямой для влажности аудитории, для выдоха — для 100 %. `np.polyval` подставляет скорость в уравнение прямой.

``` python
tauAir = np.array([3.366])      # задержки в воздухе, мс
tauBreath = np.array([3.374])   # задержки в выдохе, мс

cAir = L / (np.mean(tauAir) / 1000)
cBreath = L / (np.mean(tauBreath) / 1000)

co2Air = np.polyval(fitRoom, cAir)
co2Breath = np.polyval(fitWet, cBreath)

print("Воздух: c = %.1f м/с, CO2 = %.1f %%" % (cAir, co2Air))
print("Выдох:  c = %.1f м/с, CO2 = %.1f %%" % (cBreath, co2Breath))
```

>[!success] Должно получиться так
> ```
> Воздух: c = 344.0 м/с, CO2 = 1.3 %
> Выдох:  c = 343.2 м/с, CO2 = 3.5 %
> ```
> При 21,9 °C и 34 % из примера `conditions.txt` расчётная скорость в воздухе — 345,0 м/с, **τ** = 3,356 мс. Измеренная задержка длиннее всего на 2–3 отсчёта, а доля CO₂ в воздухе вместо 0,04 % получилась 1,3 % — это и есть точность метода. Если отметить в `air1` не провал, а соседний горб, получится **τ** = 3,322 мс и −4,5 %: доля может выйти и отрицательной, это не ошибка расчёта.

Если опытов несколько, найдите кроме среднего разброс задержек `np.std(tauAir)` и по нему оцените погрешность скорости и доли CO₂, как в [[т4.4 Время пролёта звука между микрофонами#Точность метода|т4.4]].
