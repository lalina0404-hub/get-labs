>[!info] Как распределена работа
>Программисту не нужны данные, чтобы начать: самая трудоёмкая часть — аналитическая модель скорости звука — пишется по формулам из т4.2–т4.3. Экспериментаторы тем временем настраивают установку. Руководитель изучает теорию и фотографирует установку.

>[!info] Что нужно для работы
>Стальная труба с двумя микрофонами на расстоянии 1158 мм и шлангом для выдоха, магнит-заглушка, одноразовый мундштук, [[Термогигрометр|термогигрометр]]. Для записи сигналов — готовый измеритель на плате [[Raspberry Pi Pico 2]], подключённый к Raspberry Pi по SPI.

## Стартовый набор

| Файл | Что внутри |
| --- | --- |
| `Стартовый набор/soundFunctions.py` | заготовка функции `speedOfSound()`, её пишет программист |
| `Стартовый набор/soundMeasure.py` | запускает запись на Pico, забирает оба микрофона по SPI в `data_0.txt`, `data_1.txt` и показывает график |
| `Стартовый набор/Пример данных` | записи хлопка в воздухе `air1_0.txt`, `air1_1.txt` и в выдохе `breath1_0.txt`, `breath1_1.txt`, условия опыта `conditions.txt` |

>[!warning] Отличие от пособия
>В пособии сигналы микрофонов записывает осциллограф, а время между ними измеряют курсорами на экране. В нашей установке сигналы оцифровывает микроконтроллер Raspberry Pi Pico 2 с частотой 250 кГц на канал и передаёт записи на Raspberry Pi, а задержку по ним находит программист.
