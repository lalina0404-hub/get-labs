# Лабораторный практикум «Общеинженерная подготовка» от команды [ant-lab](https://ant-lab.ru/)

Методические указания к самостоятельным лабораторным работам курса в формате Obsidian: теория, задания по ролям, стартовые наборы скриптов, примеры данных, карты понятий, навыков и инструментов.

### Инструкция

1. Установить [Obsidian](https://obsidian.md/)
2. Клонировать этот репозиторий
3. В Obsidian:
    - Открыть папку с локальной копией как хранилище
    - Разрешить плагины, когда Obsidian спросит — без них ссылки на понятия не подсвечиваются
    - Открыть заметку **Лабораторный практикум**
4. Перед лабораторной:
    - распределить роли в команде
    - прочитать теорию работы и свои задания
5. На лабораторной:
    - выполнять задания своей роли по порядку
    - сверяться с блоками «Должно получиться так»
    - сдавать результаты в репозиторий команды
6. Получать свежую версию указаний: `git pull`

### Работы

1. Расход затопленной струи
2. Свет, цвет и альбедо
3. Скорость распространения волны на поверхности воды
4. Скорость звука в газовой среде
5. Визуализация пульсовой волны
