>[!NOTE] Определение
>**Поток вектора** **U** через площадку ds с единичной нормалью **n** — величина dQ = (**U**·**n**) ds. Поток через поверхность — сумма, а в пределе интеграл, потоков через её элементы. Поток скорости жидкости равен объёмному расходу.
