**Результат** — скрипт `lightProcessing.py` превращает фотографию спектра в вектор интенсивности и знает, какая длина волны приходится на каждый его элемент. Калибровочная прямая найдена по линиям ртути.
^intro

## Задание

### Что должно получиться

- [ ] Координаты обрезки в `lightFunctions.py` подобраны под ваши фотографии
- [ ] Фотография ртутной лампы превращена в вектор интенсивности
- [ ] Найдены номера пикселей четырёх опорных пиков: 435,8, 487,7, 546,1 и 611,6 нм
- [ ] Найдена калибровочная зависимость длины волны от номера пикселя — 4 балла
- [ ] Необязательно: пики находятся скриптом автоматически — +1 балл

### Как проверить

1. **Наклон правдоподобный.** На примере данных получается около 0,62 нм на пиксель, а камера видит примерно от 415 до 660 нм.
2. **Проверочные пики на своих местах.** Жёлтый дублет ртути ложится около 579 нм, ступенька красного канала — около 590 нм.

## Ход работы

Начинайте на фотографиях примера из стартового набора, а когда экспериментатор сделает свои, перейдите на них.

### 1. Подключить функции

``` python
import numpy as np
import matplotlib.pyplot as plt
import lightFunctions as light

dataPath = "light/data/"
plotsPath = "light/plots/"
```

Как устроена `readIntensity()`, разобрано в [[т2.4 Экспериментальная установка спектрометра#Фотография как массив чисел|т2.4]]. Она возвращает вектор яркости, а заодно рисует график трёх каналов поверх самого спектра и сохраняет его в файл.

### 2. Подобрать обрезку

Откройте свою фотографию ртутной лампы и посмотрите, в каких строках и столбцах лежит спектр:

``` python
import imageio
photo = imageio.imread(dataPath + "white-mercury.png")
plt.imshow(photo)
plt.show()
```

Наведите курсор на углы полосы спектра: внизу окна Matplotlib показывает координаты. Вырезайте полосу чуть уже, чем она есть, чтобы края щели с неровной яркостью не попали в среднее. Впишите координаты в переменные `ROWS` и `COLS` в начале `lightFunctions.py`. На снимках примера спектр занимает строки ≈ 460–850 и столбцы ≈ 1140–1335.

### 3. Найти опорные пики

Постройте интенсивность фотографии ртутной лампы по пикселям, по каждому каналу отдельно. Найдите пики по таблице из [[т2.3 Дифракционная решётка и калибровка спектрометра#Как узнать линии на снимке|т2.3]]: синюю линию ртути — в синем канале, пик люминофора 487,7 нм — в синем и зелёном сразу, зелёную линию ртути — самый яркий пик, красный пик люминофора — самый яркий в красном канале.

>[!success] Должно получиться так
>![[п2.4 Спектр ртутной лампы по пикселям.png]]
>
>На примере опорные пики около 60-го, 142-го, 228-го и 344-го пикселей. Проверочные — небольшой зелёный пик около 289-го и красная ступенька около 306-го.

**Глазами и руками.** Увеличьте график вокруг каждого пика и запишите номер пикселя вершины.

**Скриптом (+1 балл).** В SciPy есть функция поиска пиков:

``` python
from scipy.signal import find_peaks
peaks, _ = find_peaks(blue, prominence=20)
```

`prominence` — насколько пик должен возвышаться над соседями, чтобы считаться пиком. Подберите её так, чтобы находились настоящие линии, а не шум.

### 4. Калибровочная прямая

``` python
peaks = [435.8, 487.7, 546.1, 611.6]   # нм
pixels = [...]                         # ваши номера пикселей
fit = np.polyfit(pixels, peaks, 1)
wavelength = np.polyval(fit, np.arange(len(intensity)))
```

Постройте график калибровки: точки «пиксель — длина волны» и прямую с формулой в легенде. Проверьте прямую по проверочным пикам, как в «Как проверить».
