**Результат** — экспериментаторы написали короткий скрипт `lightMeasure.py`, который снимает спектр камерой Raspberry Pi с постоянными выдержкой, усилением и балансом белого, сохраняет снимок с говорящим именем и сразу сообщает, нет ли пересвета. Выдержка подобрана и записана.
^intro

## Задание

### Что должно получиться

- [ ] `python3 lightMeasure.py <имя> <выдержка>` сохраняет снимок 2560×1440 в `data/<имя>.png`
- [ ] Скрипт печатает максимум по каналам R, G, B и предупреждает о пересвете
- [ ] Спектр на снимке ориентирован так же, как на примерах: синий сверху
- [ ] Выдержка подобрана на белом листе под лампой накаливания: максимум по каналам 150–220, без 255
- [ ] Выдержка, усиление и баланс белого записаны для отчёта

### Как проверить

1. **Спектр виден.** На снимке вертикальная радужная полоса на тёмном фоне.
2. **Пересвет определяется верно.** Снимок с очень большой выдержкой скрипт помечает как пересвеченный, а подобранный — нет.
3. **Повторяемость.** Два снимка подряд одного и того же листа дают почти одинаковые максимумы.

## Ход работы

### 1. Первый снимок из терминала

На Raspberry Pi установки снимают командой `raspistill`. В папке работы создайте папку `data` и сделайте пробный снимок:

``` bash
mkdir -p data
raspistill -n -t 1000 -w 2560 -h 1440 -rot 180 -ss 20000 -ISO 100 -awb off -awbg 1.5,1.5 -e png -o data/test.png
```

| Параметр | Смысл |
| --- | --- |
| `-n` | без окна предпросмотра |
| `-t 1000` | снять через 1 с после включения камеры |
| `-w 2560 -h 1440` | разрешение, как у примеров |
| `-rot 180` | камера закреплена вверх ногами |
| `-ss 20000` | выдержка в микросекундах |
| `-ISO 100` | усиление сигнала матрицы |
| `-awb off -awbg 1.5,1.5` | автоматический баланс белого выключен, усиление красного и синего каналов задано вручную |
| `-e png -o …` | формат и имя файла |

Выдержку, усиление и баланс белого задают руками потому, что иначе камера сама подстроит их под каждый кадр: белый лист сделает темнее, синий — ярче, и отношение спектров, ради которого всё делается, потеряет смысл, см. [[т2.2 Альбедо#Как измерить альбедо камерой|т2.2]].

### 2. Скрипт съёмки

Набирать длинную команду для каждого из десятка снимков неудобно, а пересвет хочется видеть сразу. Напишите короткий скрипт, который получает имя снимка и выдержку из командной строки.

>[!success] Должно получиться так
> ```python
> # lightMeasure.py — снимок спектра с постоянными настройками
> #   python3 lightMeasure.py white-tungsten 50000
> import subprocess
> import sys
> import imageio
>
> name = sys.argv[1]          # имя снимка без .png
> shutter = sys.argv[2]       # выдержка, мкс
>
> # снять командой raspistill с параметрами из таблицы: subprocess.run([...], check=True)
> # прочитать снимок и оставить только каналы R, G, B
> # напечатать максимум по каждому каналу
> # если где-то 255 — напечатать, что выдержку надо уменьшить
> ```

| Что нужно | Где подсмотреть |
| --- | --- |
| запустить команду из Python | `subprocess.run(["raspistill", "-n", ...], check=True)`: каждый параметр — отдельная строка списка |
| только каналы R, G, B | `photo[:, :, :3]`: четвёртое число в PNG с камеры служебное и всегда равно 255 |
| максимум по каналам | `photo.max(axis=(0, 1))` |


>[!success] Должно получиться так
> ```
> $ python3 lightMeasure.py white-tungsten 50000
> white-tungsten: R=170 G=119 B=82
> ```

### 3. Подобрать выдержку

Подбирайте выдержку на **белом листе под лампой накаливания** — это самый яркий снимок серии. Если где-то 255, уменьшите выдержку вдвое, если все три максимума меньше 150 — увеличьте. Хороший максимум — 150–220: сигнала много, пересвета нет, и пиксели попадают в ту часть тоновой кривой, где камера искажает свет меньше всего, см. [[т2.5 Нелинейность камеры#^intro|т2.5]]. На установке курса для лампы накаливания это около 50 000 мкс, для белого светодиода — около 120 000 мкс.

Для ртутной лампы выдержку можно подобрать отдельно: её снимок нужен только для калибровки длины волны, и яркость на нём не сравнивается с другими.

### 4. Записать настройки

Когда выдержка подобрана, все снимки лампы накаливания отличаются только именем: `white-tungsten`, `red-tungsten` и так далее. Так имена совпадут с примером, и программисту не придётся переименовывать файлы. Выдержку, усиление и баланс белого передайте руководителю для методики измерений, а скрипт отправьте в `light/scripts` репозитория команды.
