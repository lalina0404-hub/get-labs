Спектрометр установки собран из объектива, щели, дифракционной решётки и камеры Raspberry Pi. На выходе у него фотография. Как свет проходит через установку и как из фотографии получить кривую интенсивности, с которой работают формулы?
^intro

## Устройство спектрометра

В установке используются:

- **объектив** — фокусирует свет, отражённый от исследуемой поверхности;
- **регулируемая щель** — вырезает узкую полоску изображения, чтобы линии спектра были тонкими;
- **дифракционная решётка** — раскладывает свет на спектральные составляющие, см. [[т2.3 Дифракционная решётка и калибровка спектрометра#^intro|т2.3]];
- **камера** со светочувствительной матрицей, подключённая к Raspberry Pi.

![[т2.4 Спектрометр снаружи.jpeg]]

![[т2.4 Спектрометр внутри.jpeg]]

Корпус светонепроницаемый: посторонний свет комнаты добавился бы ко всем снимкам и испортил отношение спектров. Лампу и лист располагают так, чтобы объектив смотрел на освещённый лист, а не на саму лампу.

![[т2.4 Камера Raspberry Pi.jpeg]]

Камера закреплена на корпусе спектрометра неподвижно: от её положения зависит, на какие пиксели попадает спектр.

## Фотография как массив чисел

![[КМОП-матрица#^def]]

Python читает снимок как трёхмерный массив чисел: строки, столбцы и каналы цвета. Снимок камеры установки — 1440 строк и 2560 столбцов, а у каждого пикселя числа от 0 до 255: яркость в красном, зелёном и синем каналах. Четвёртое число в PNG с камеры — служебное, оно всегда 255, поэтому в коде берут только первые три канала: `0:3`.

``` python
import imageio
photo = imageio.imread("white-mercury.png")
print(photo.shape)        # (1440, 2560, 4): строки, столбцы, каналы
```

Спектр на снимке — вертикальная полоса. Сверху вниз вдоль неё растёт длина волны: синий вверху, красный внизу. В каждой строке полосы одна и та же длина волны повторяется во всех столбцах — это изображение щели. Значит, чтобы получить интенсивность для каждой длины волны, нужно:

1. вырезать из снимка прямоугольник, в котором лежит полоса;
2. в каждой строке усреднить яркость по столбцам — так шум отдельных пикселей сглаживается;
3. получить по одному числу на строку для каждого канала.

Функция `readIntensity()` из `lightFunctions.py` делает именно это:

``` python
cut = photo[430:870, 1190:1290, 0:3].swapaxes(0, 1)
rgb = np.mean(cut, axis=(0))
luma = 0.2989 * rgb[:, 0] + 0.5866 * rgb[:, 1] + 0.1144 * rgb[:, 2]
```

Разберём по шагам:

| Что делает | Форма массива |
| --- | --- |
| `photo[430:870, 1190:1290, 0:3]` — вырезает строки 430–870 вдоль спектра, 100 столбцов посередине полосы и каналы R, G, B | (440, 100, 3) |
| `.swapaxes(0, 1)` — меняет местами строки и столбцы, чтобы столбцы стали первой осью | (100, 440, 3) |
| `np.mean(cut, axis=(0))` — усредняет по первой оси, то есть по 100 столбцам | (440, 3): для каждой из 440 строк — средние R, G, B |
| `luma = …` — складывает три канала с весами в одно число | (440,) |

Перестановка осей здесь не обязательна: тот же результат даёт `np.mean(photo[430:870, 1190:1290, 0:3], axis=1)`, то есть усреднение сразу по столбцам. Так функция написана в стартовом наборе, на результат перестановка не влияет.

Перед обрезкой снимок выпрямляют. Камера стоит чуть повёрнутой относительно щели, на установке курса примерно на 5°, поэтому линии спектра на снимке идут не точно поперёк полосы, а с наклоном. Функция `straighten()` поворачивает участок со спектром обратно на угол `ANGLE`. Если на графике с фоном-снимком линии всё ещё наклонены, подберите угол для своей установки.

Координаты обрезки подобраны для снимков примера и вынесены в переменные `ROWS` и `COLS` в начале `lightFunctions.py`.

![[Яркость пикселя#^def]]

Последняя строка кода складывает три канала с весами, которые учитывают чувствительность глаза: зелёный свет глаз воспринимает самым ярким, синий — самым тусклым. Эти веса из стандарта цветного телевидения дают яркость, близкую к фотометрической из [[т2.1 Свет и спектр#^intro|т2.1]].

>[!warning] Координаты обрезки у каждой установки свои
>Положение спектра на снимке зависит от того, как стоят камера и решётка. Координаты в `lightFunctions.py` подобраны для фотографий примера. Для своих снимков их нужно подобрать заново, иначе в обрезку попадёт тёмный фон или край спектра.

>[!warning] Пересвет
>Если пиксель получил больше света, чем может измерить, он насыщается и показывает 255, сколько бы света ни было на самом деле. В пересвеченной части спектра отношение интенсивностей теряет смысл. Перед обработкой проверьте, что максимум каждого канала в обрезке меньше 250.
