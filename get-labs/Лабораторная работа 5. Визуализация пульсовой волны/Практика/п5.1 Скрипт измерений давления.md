**Результат** — скрипт `bloodMeasure.py` на основе вашего скрипта с занятия по АЦП записывает отсчёты MCP3021 заданное число секунд, печатает частоту дискретизации и сохраняет запись в файл с длительностью и датой.
^intro

## Задание

### Что должно получиться

- [ ] В папке с вашим именем на рабочем столе лежат `mcp3021_driver.py` с занятия по АЦП и новый `bloodMeasure.py`
- [ ] АЦП отзывается на давление: если сжать грушу, отсчёты растут
- [ ] Скрипт пишет отсчёты в цикле заданное время и сохраняет их в файл

### Как проверить

1. **Отсчёты отзываются на давление.** Если сжать грушу тонометра, отсчёты растут на десятки и сотни единиц, если открыть клапан — падают.
2. **Частота.** Скрипт печатает частоту дискретизации — больше тысячи отсчётов в секунду.

## Ход работы

### 1. Подготовить папку

1. Создайте на рабочем столе Raspberry Pi папку с вашим именем.
2. Скопируйте в неё `mcp3021_driver.py` из своего репозитория `get` — драйвер АЦП, который вы писали на занятии по АЦП.
3. Создайте в той же папке пустой `bloodMeasure.py`.

### 2. Проверить датчик

Датчик давления подключён к разъёму блока 5 В платы get-adc. Выведите шину I2C на выводы, как на занятии по АЦП: `raspi-gpio set 2 a0` и `raspi-gpio set 3 a0`. Затем в интерпретаторе Python читайте отсчёт и сжимайте грушу:

``` python
from mcp3021_driver import MCP3021
adc = MCP3021(5.0)
print(adc.get_number())
adc.deinit()
```

Число должно расти, когда давление в манжете растёт.

>[!warning] Если число не меняется
>Если АЦП отвечает, но число стоит на месте, давление до него не доходит. Проверьте по порядку:
>1. мультиметром — меняется ли напряжение на выходе датчика, когда сжимают грушу;
>2. трубку от датчика: вставлена ли она в тройник на магистрали манжеты и не пережата ли;
>3. перемычку источника на блоке 5 В платы: на вход АЦП должен идти внешний разъём, а не встроенный датчик.

### 3. Написать скрипт

Возьмите за основу скрипт `mcp.py` с занятия по АЦП: он уже измеряет в цикле заданное время. Добавьте то, чего в нём не было: сохранение в файл. Цикл и формат файла разобраны в [[о3 Raspberry Pi и АЦП#Цикл измерений по времени|о3]].

>[!success] Должно получиться так
> ```python
> # bloodMeasure.py
> #   python3 bloodMeasure.py "40 mmHg" 10
> import sys
> import time
> from mcp3021_driver import MCP3021
>
> name = sys.argv[1]               # имя файла без .txt
> duration = float(sys.argv[2])    # секунд
>
> # создать объект АЦП
> try:
>     # start = time.time()
>     # пока не прошло duration секунд: добавлять в список adc.get_number()
>     # finish = time.time()
> finally:
>     # освободить шину
> # напечатать число отсчётов и частоту
> # сохранить отсчёты, длительность и дату в data/<name>.txt
> ```

В цикле — только чтение АЦП и добавление в список: без печати и без пересчёта в вольты. Тогда частота будет больше тысячи отсчётов в секунду. Сохраняйте целые отсчёты `get_number()`, а не напряжение: в давление их переведёт калибровка.

>[!success] Должно получиться так
> ```
> $ python3 bloodMeasure.py test 3
> Отсчётов: 5546, частота 1849 Гц
> ```

Отправьте `bloodMeasure.py` и `mcp3021_driver.py` в `blood/scripts` репозитория команды.
