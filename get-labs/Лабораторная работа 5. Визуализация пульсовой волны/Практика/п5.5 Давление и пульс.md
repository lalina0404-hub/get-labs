## Ход работы

Записи в покое и после нагрузки обрабатываются одинаково. Оформите обработку функцией, которая получает имя записи, и вызовите её дважды. Образцы в шагах 1–5 — для записи в покое из примера данных, в шаге 6 — для записи после нагрузки.

### 1. Давление в манжете

Переведите отсчёты в мм рт. ст. калибровкой из п5.4. Время каждого отсчёта — `np.linspace(0, duration, count)`. Сгладьте шум квантования скользящим средним по 50 мс, как в [[т5.4 Выделение пульсовой волны#Шум квантования|т5.4]]. Постройте давление от времени.

``` python
samples, duration, count = read(dataPath + "rest.txt")
p = np.polyval(fit, samples)                 # давление, мм рт. ст., fit — прямая из п5.4
time = np.linspace(0, duration, count)       # время, с
rate = count / duration                      # отсчётов в секунду

window = int(rate * 0.05)                    # сглаживание по 50 мс
p = np.convolve(p, np.ones(window) / window, mode="same")
plt.plot(time, p)
```

>Манжету накачали до 172 мм рт. ст. и на первой секунде приоткрыли клапан. Дальше давление ровно спускается примерно на 2,4 мм рт. ст. в секунду. Мелкие зубцы на линии — пульсовые волны. Скачок около 26 с — испытуемый шевельнул рукой.

### 2. Пульсации

Найдите медленный тренд скользящим средним по 1,5 с и вычтите его из давления, как в [[т5.4 Выделение пульсовой волны#Как найти тренд|т5.4]]. Останутся одни пульсации. Постройте их на участке от 10 до 30 секунд от начала записи и отметьте пики.

``` python
window = int(rate * 1.5)
trend = np.convolve(p, np.ones(window) / window, mode="same")
osc = p - trend                              # пульсации

from scipy.signal import find_peaks
peaks, _ = find_peaks(osc, distance=0.4 * rate, prominence=0.3)
plt.plot(time, osc)
plt.plot(time[peaks], osc[peaks], "r.")
plt.xlim(10, 30)
```

`distance` — наименьшее расстояние между пиками в отсчётах, 0,4 с: два удара сердца ближе друг к другу не бывают. `prominence` — насколько пик выступает над соседними впадинами, мм рт. ст.: мелкий шум с меньшей выраженностью пиком не считается.

>[!success] Должно получиться так
>![[п5.5 Пульс в покое.png|500]]
>
>Каждый пик — один удар сердца. Высокий пик около 26 с — удар, на который наложилось движение руки. Это тоже удар, его считают.

### 3. Пульс

Сосчитайте пики на участке 10–30 с и найдите пульс по формуле из [[т5.4 Выделение пульсовой волны#Пульс|т5.4]]. Пики участка удобно отобрать по времени:

``` python
inside = peaks[(time[peaks] > 10) & (time[peaks] < 30)]
pulse = (len(inside) - 1) * 60 / (time[inside[-1]] - time[inside[0]])
```

На образце из шага 2 — 25 пиков, первый на 10,6 с, последний на 29,7 с:

$$
\text{пульс} = \frac{(25 - 1)\cdot 60}{29{,}7 - 10{,}6} \approx 76 \text{ ударов в минуту}.
$$

Для обеих записей берите один и тот же участок 10–30 с. После нагрузки пульс во время записи заметно падает — человек восстанавливается. В примере в первые 10 секунд записи пульс 118, в последние — 90. Если считать на разных участках, сравнение до и после нагрузки потеряет смысл.

### 4. Систолическое и диастолическое давление

Давления находят по правилам из [[т5.2 Осциллометрический метод#Как найти давления по записи|т5.2]]:

- **систолическое давление** — давление в манжете в момент 5-й пульсовой волны после их появления;
- **диастолическое давление** — давление в момент, когда амплитуда пульсовых волн заметно уменьшается.

Оба момента ищут глазами. Пятую волну удобно отсчитать на графике пульсаций: постройте его не на 10–30 с, а с самого начала спуска. Уменьшение амплитуды лучше видно на графике амплитуды волн. Для каждой волны найдите амплитуду — разность между вершиной волны и впадиной перед ней — и постройте её от времени:

``` python
from scipy.signal import find_peaks

troughs, _ = find_peaks(-osc, distance=0.4 * rate, prominence=0.3)
amp, tAmp = [], []
for a, c in zip(troughs[:-1], troughs[1:]):
    top = a + np.argmax(osc[a:c])        # вершина волны между двумя впадинами
    amp.append(osc[top] - osc[a])
    tAmp.append(time[top])
```

Берите только участок спуска: от момента, когда приоткрыли клапан, до 40 мм рт. ст. Давление в найденные моменты берите с графика давления из шага 1.

>[!success] Должно получиться так
>![[п5.5 Амплитуда волн, систола и диастола в покое.png|500]]
>
>- Голубые точки — амплитуда каждой волны. Синяя линия — сглаженная амплитуда: медиана по семи соседним волнам. Волны от движения руки, которые в полтора раза выше соседних, убраны.
>- Красные кружки — первые пять волн. Пятая волна — на 6,5 с, давление в манжете в этот момент 158 мм рт. ст. Это систолическое давление.
>- Амплитуда растёт до 20–25 с, потом на 33,6 с резко падает ниже зелёной линии 0,8 от наибольшей. Давление в этот момент 93 мм рт. ст. Это диастолическое давление.
>- Около 40–44 с амплитуда снова чуть подрастает — это разброс отдельных волн. Диастолой берут первое заметное уменьшение.

>[!warning] Пульсации с самого начала записи
>На примере данных пульсовые волны видны с самого начала спуска, при 166 мм рт. ст., и уже довольно большие. Поэтому «появление волн» здесь — это начало спуска, и систолическое давление 158 мм рт. ст. получилось высоким. Скорее всего, манжету накачали недостаточно высоко или надели неплотно.
>
>На своей записи проверьте: если волны видны с самого начала, накачайте манжету выше и повторите запись. Волны должны появиться не сразу, а через несколько секунд спуска.

Что из этого следует:

На примере данных к тому же волны видны с самого начала записи, поэтому систолическое давление может быть завышено. Поэтому абсолютные значения давлений — оценка, надёжнее сравнивать давления до и после нагрузки между собой.
